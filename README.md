# Roncalli Modern Portfolio Theory Exercises

This repository contains Python implementations of selected exercises from Roncalli (2013) *Introduction to Risk Parity and Budgeting*. The exercises focus on **Modern Portfolio Theory** and include:

- **Markowitz Optimized Portfolios**: Implementation of mean-variance optimization.
- **Efficient Frontier Variations**: Exploration of portfolio risk-return trade-offs.
- **Sharpe Ratio Analysis**: Calculation of single-asset and portfolio Sharpe ratios.
- **Tangency Portfolio**: Computation of the optimal risk-adjusted portfolio including a risk-free asset.

The code is written using **NumPy**, **Pandas**, **SciPy**, and **Matplotlib**, and includes step-by-step calculations and visualizations of key portfolio metrics.

This project is useful for students and practitioners in **quantitative finance**, or anyone interested in portfolio optimization techniques.
